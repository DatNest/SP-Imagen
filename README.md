## Что такое SP Imagen?

SP Imagen — самостоятельное расширение для генерации изображений по ролевым постам с помощью NovelAI. Текстовая модель выступает в роли режиссёра: читает события чата, выбирает композицию и видимые детали, а затем составляет задание для художника.

Больше не нужно каждый раз вручную собирать внешность персонажей, их одежду и описание сцены. Готовые иллюстрации сохраняются в галерее соответствующего поста.

### Три формата — три способа рассказать историю

| Профиль | Для чего |
| :--- | :--- |
| **Snapshot** | Один выразительный кадр: портрет, взаимодействие, атмосферная сцена или важный момент. |
| **Comic** | Несколько панелей одного момента: эмоции, реакции, крупные планы и диалоги. |
| **Story Page** | Страница с последовательностью уже произошедших событий ролевой. |

Для Comic и Story Page можно включать или отключать речевые пузыри и надписи, а также отдельно настраивать количество реплик и их длину.

## Установка

Для работы понадобятся:

- [SillyTavern](https://github.com/SillyTavern/SillyTavern).
- Доступ к текстовой модели через профиль подключения SillyTavern или прямой OpenAI-совместимый API.
- Аккаунт [NovelAI](https://novelai.net/) с доступом к генерации изображений и собственный API-токен.

**Установка через SillyTavern:**

1. Открой меню расширений.
2. Нажми **Install extension** (установка расширения).
3. Вставь ссылку:

   ```text
   https://github.com/DatNest/SP-Imagen
   ```

4. Установи расширение и обнови страницу SillyTavern.
5. Открой **SP Imagen** через меню волшебной палочки или настройки расширений.

Tavern Helper, ExtBlocks и SillyImages для работы SP Imagen не требуются.

## Первый запуск

### 💡 Быстрый гайд

В главном окне SP Imagen есть интерактивный **«Быстрый гайд»**. Он сам открывает нужные разделы, подсвечивает кнопки и объясняет, как ими пользоваться.

Обучение можно проходить в своём темпе, возвращаться к предыдущим шагам или прерывать в любой момент. Учебная генерация не отправляет запросы к моделям и не расходует токены или Anlas.

Возле настроек также есть кнопочки **?** с пояснениями.

<details>
<summary><b>1. Подключаем текстовую модель</b></summary>

Открой **SP Imagen → Настройки → Текстовая модель**.

Выбери один из вариантов:

- Готовый профиль подключения SillyTavern.
- Прямой OpenAI-совместимый API: адрес сервера, ключ и модель.

Нажми **«Проверить подключение»**, затем сохрани настройки. Именно эта модель будет читать ролевую и составлять промпты.

</details>

<details>
<summary><b>2. Подключаем NovelAI</b></summary>

Открой **SP Imagen → Настройки → NovelAI**.

Введи свой постоянный API-токен NovelAI, выбери модель и проверь подключение. SP Imagen генерирует самостоятельно; SillyImages не используется.

Для начала остальные параметры можно оставить стандартными. Поддерживаются модели семейства NAI V5, включая Full, Full Medium и Curated.

Опция **«Ни в коем случае не тратить Anlas»** включена по умолчанию. Она проверяет условия бесплатной генерации перед отправкой запроса. Если эти условия не выполняются или лимит не удаётся подтвердить, генерация блокируется.

Не передавай свой API-токен другим людям и не публикуй файлы настроек с ключами.

</details>

<details>
<summary><b>3. Подготавливаем персонажей и стиль</b></summary>

Добавь постоянную внешность своих героев в библиотеку. При желании выбери художественный стиль и настрой источники одежды в разделе подготовки изображения.

После этого можно возвращаться в ролевой чат и генерировать первую иллюстрацию.

</details>

## Библиотека персонажей

Храни внешность своих персонажей в одном месте, независимо от конкретной ролевой. Создавай карточки персон и персонажей, добавляй иконки, псевдонимы, поисковые метки и данные для промпта.

Библиотеку можно просматривать компактным списком или сеткой карточек.

### Конструктор внешности

Внешность можно записывать обычным текстом или организовать в каталог тегов, разделив их на удобные группы: лицо, волосы, фигура, руки, особые приметы и любые собственные разделы.

| Режим | Что в нём хранить |
| :--- | :--- |
| **Ракурсы** | Постоянные черты внешности, распределённые по видимым частям тела. |
| **Под одеждой** | Шрамы, родинки, татуировки и другие детали открытой кожи. |
| **NSFW** | Отдельные особенности анатомии взрослых персонажей. |

Выбирай нужный ракурс и назначай ему теги из левой колонки. Справа отображаются выбранные признаки. Так в крупный план лица не нужно добавлять описание ног, а детали под одеждой не должны появляться без соответствующего контекста.

**✦ Показывать всегда** — для признаков, которые нужны при любом ракурсе.

Визуальная подсказка показывает, какие области тела относятся к выбранному ракурсу.

<details>
<summary><b>Инструменты конструктора тегов</b></summary>

| Значок | Действие |
| :---: | :--- |
| ✎ | Переименовать тег |
| 🗑 | Удалить тег |
| ✥ | Изменить порядок выбранного тега стрелками |
| ⇄ | Перенести тег в нужный режим и раздел |
| ↶ / ↷ | Отменить / повторить изменение |

Для переноса включи ⇄ и нажми нужный тег. Выбери режим, затем раздел, если в нём есть разделы. При переносе внутри режима назначения сохраняются; после переноса в другой режим назначь тег нужным областям заново.

</details>

### Другие имена и данные для промпта

Добавляй имена, прозвища и сокращения, которыми герой пользуется в ролевой. Это помогает распознавать одного персонажа под разными именами.

В отдельной вкладке можно указать имя для промпта и категорию персонажа — например, `girl`, `boy` или `other`. Количество видимых участников рассчитывается автоматически.

### Одежда

Постоянную внешность и текущую одежду лучше хранить отдельно. В настройках подготовки изображения можно выбрать источники гардероба: метки в сообщениях, описание карточки и описание персоны.

Для английских записей сохраняются исходные формулировки и усиления тегов; русские описания режиссёр переводит на английский.

## Иллюстрации в чате

Нажми **✧** у нужного поста и выбери формат генерации. SP Imagen подготовит контекст, определит участников и составит промпт для NovelAI.

Можно включить предварительный просмотр итогового промпта в настройках генерации.

Готовое изображение появится прямо у поста. Если хочется попробовать другой вариант, не нужно создавать новый пост или начинать всю подготовку заново.

| Кнопка | Что делает |
| :---: | :--- |
| ✧ | Запустить новую генерацию |
| ↪ | Продолжить незавершённую генерацию, если есть черновик |
| ▤ | Посмотреть сохранённые этапы подготовки и итоговый промпт |
| ← / → | Листать изображения |
| 📝 | Отредактировать промпт или выбрать стиль для одной картинки |
| ↻ | Перегенерировать изображение |
| ↓ | Скачать изображение |
| 🗑 | Удалить изображение с подтверждением |

Нажатие на изображение открывает полноэкранный просмотр. При перегенерации из готового промпта повторный запрос к текстовой модели не нужен; условия расхода Anlas определяются настройками NovelAI.

## Настрой под себя

В SP Imagen можно создавать собственные профили, дополнительные инструкции режиссёру и художественные стили. Все встроенные форматы доступны и без ручного редактирования промптов.

- **Профили** — форматы и собственные режиссёры.
- **Все промпты** — расширенная настройка системных инструкций.
- **Подготовка изображения** — количество читаемых постов, источники одежды, лимиты реплик и очистка технических вставок.
- **Художественные стили** — отдельные теги оформления, которые можно менять независимо от внешности персонажей.

## Сохранение и резервные копии

Библиотека хранится в пользовательских данных SillyTavern. Внизу окна библиотеки доступны:

| Значок | Действие |
| :---: | :--- |
| ↧ | Экспорт библиотеки вместе с иконками и тегами |
| ↥ | Импорт библиотеки в черновик |
| ◷ | История предыдущих сохранений |

После импорта или редактирования нажми **«Сохранить»**. Пять предыдущих сохранений доступны в истории. Особенно важные библиотеки, стили и иллюстрации стоит дополнительно сохранять на своём устройстве.
