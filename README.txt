SP Imagen 2.9.0 — автономная версия для SillyTavern

УСТАНОВКА
1. Сделай резервную копию текущего расширения, библиотеки, пользовательских промптов и настроек.
2. Закрой SillyTavern и замени старую папку SP_IMAGEN_EXTENSION папкой из этого архива.
   Не устанавливай две копии SP Imagen одновременно.
3. Если раньше был установлен отдельный скрипт NESS/SP Imagen Media Slots в Tavern Helper,
   отключи его, чтобы старые кнопки не дублировались.
4. Перезапусти SillyTavern и обнови страницу с очисткой кэша (Ctrl+F5).

НАСТРОЙКИ
• Настройки библиотеки, сохранённые промпты, стили и предыдущие данные сохраняются
  в прежних ключах SillyTavern; удалять их не нужно.
• SP Imagen → Текстовая модель: выбери сохранённый профиль подключения
  SillyTavern или настрой прямой OpenAI-совместимый endpoint.
• SP Imagen → NovelAI: включи «Генерировать напрямую через NovelAI»,
  укажи постоянный API-токен NovelAI и модель.
• SP Imagen больше НЕ вызывает другие расширения для создания изображений,
  не создаёт временных скрытых RP-постов и не зависит от SillyImages.
• Параметр «Никогда не тратить Anlas» включён по умолчанию и проверяет
  право на бесплатную генерацию до отправки запроса.

ОДЕЖДА И ОЧИСТКА (2.8.3)
• В настройках генерации открой «Откуда брать одежду». Источники идут по порядку:
  1) сообщения чата — готовые метки, свои метки, оба формата или отключено;
  2) поле «Описание» активной карточки персонажа, включая нарратора;
  3) описание активной персоны. Второй и третий источники необязательные.
• Для метки в сообщении укажи текст до имени, после имени и после описания одежды.
  Пример создаётся сразу, его можно скопировать. Новые поля не стирают старые настройки.
• При конфликте одежды актуальная запись из чата имеет приоритет перед карточкой.
• «Что скрывать от режиссёра» показывает короткие примеры до/после для каждой галочки.
• «Посмотреть итоговый промпт перед отправкой в NovelAI» — одна галочка.
• «Настроить по примеру» поможет создать правило удаления или извлечения одежды:
  выбрать цель → вставить фрагмент → проверить → добавить → сохранить настройки.
• Изменение настроек обработки касается копии чата, сам текст RP не редактируется.

БЫСТРЫЙ ГАЙД (2.8.4)
• В конце обучения можно пройти весь запуск под настоящим RP-постом: звёздочка ✧,
  выбор Snapshot/Comic/Story Page, пример сохранённого промпта и галерея.
• В учебном режиме никакая текстовая или графическая модель не вызывается.
  Временный значок ▤ и пример промпта не записываются в чат.
• При начале новой учебной генерации значок предыдущего учебного примера исчезает.
  Существующие настоящие изображения и их промпты не удаляются.
• Прерывание, Escape, окончание гайда и переключение чата очищают учебные элементы.
• Если под постом есть готовая картинка с сохранённым промптом, обычная кнопка ▤
  позволяет прочитать текст этого промпта. Ничего не перегенерируется.

ИНТЕРФЕЙС
• Открывается из настроек расширений или меню волшебной палочки.
• Под RP-сообщениями доступны Snapshot, Comic и Story Page; собственная
  галерея хранится в данных конкретного сообщения и чата.
• Для обновления существующего изображения используй ↻ в его галерее.

ДИАГНОСТИКА
• При неполном ответе режиссёра расширение повторяет текстовый запрос один раз;
  исходный ответ остаётся в переменной sp_imagen_last_director_raw текущего чата.
• При сбоях проверь консоль браузера (F12) и сообщения SP Imagen.
• В тестах без реального аккаунта проверены парсер, ZIP NovelAI, работа текстового
  профиля, интерфейс галереи, переключение чатов и очистка обработчиков.
  Реальная генерация с подпиской и вашим сервером SillyTavern НЕ тестировалась.

ОФИЦИАЛЬНЫЕ ПРОМПТЫ
Файл official-prompts.js перенесён из исходной версии без изменений,
байт в байт. Сохранённые пользовательские промпты автоматически не стираются.

Безопасность: токены остаются в настройках клиента SillyTavern; не публикуй
экспорт настроек или файлы конфигурации с ключами.

SP Imagen 2.3.0
----------------
Все окна SP Imagen можно свернуть кнопкой «−» в заголовке и вернуть кнопкой «□».
В разделе «Промпты» → «Импорт / экспорт JSON» можно импортировать файл .json
или вставить JSON текстом, выгрузить текущие промпты, а также скачать шаблон
SP_IMAGEN_prompts_TEMPLATE.json, где каждое из трех полей промпта = "test".
Файл-шаблон — только образец структуры; для реальной генерации нужно
заменить "test" полноценными промптами. Импорт заменяет три промпта только
после явного подтверждения. Официальные промпты внутри расширения не менялись.


SP Imagen 2.4.0 — подключение и описания внешности (предыдущий релиз)
---------------------------------------------------
• Оба окна подключения строятся сразу, до любых сетевых действий. Поля
  текстовой модели не пропадают, даже если получение профилей SillyTavern
  не завершается. Список можно вручную обновить; сохранённый ID профиля
  остаётся выбранным и при временном сбое получения списка.
• В NovelAI при сбое подготовки формы показывается текст ошибки, а не
  одно название окна. Кнопки сворачивания работают с обоими окнами.
• Полная базовая внешность вставляется по умолчанию. Если выбранный
  ракурс пуст, подставляется всё базовое описание, даже если для других
  ракурсов настроены отдельные фрагменты.
• Если режиссёр пропустил техническую метку внешности, но указал точное
  имя известного библиотечного персонажа в отдельном блоке участника,
  код подставляет его базовое описание; незнакомцев не создаёт.
  Метка none по-прежнему означает намеренный силуэт/невидимые детали.
• Общая логика ракурсов объединена в одном модуле appearance-visibility.js
  вместо повторявшихся реализаций в runtime.js и library-runtime.js.
• Тексты режиссёрских и официальных промптов не редактировались.

ПРОВЕРКИ 2.4.0
• Синтаксис всех JS-файлов, офлайн-тесты транспорта/NovelAI/JSON и 8
  вариантов пустых ракурсов; браузерный стенд на изолированных подстановках
  API подтвердил полную отрисовку двух окон и сохранение полей при сворачивании.
• Полный запуск именно в пользовательской SillyTavern и авторизованные
  запросы к аккаунту NovelAI в этом окружении не проверялись.

SP Imagen 2.5.0 — изоляция и закрытие окон
-----------------------------------------
• При загрузке НЕ читаются настройки ExtBlocks; библиотека, промпты и генерация принадлежат SP Imagen.
• Внутреннее состояние чатов использует имена sp_imagen_*, чтобы избежать конфликтов со старыми naicom-переменными.
  Сохраняемые пользовательские настройки чата, состав участников и последний промпт импортируются однократно из предыдущей версии SP Imagen.
• Кнопка «Посмотреть последний промпт» находится на главной странице SP Imagen; можно посмотреть итоговый запрос NovelAI
  и исходный ответ режиссёра. Итоговый запрос сохраняется перед обращением к NovelAI, в том числе если сама генерация завершится ошибкой.
• Основные окна имеют отдельные кнопки свернуть/развернуть и ×, общую реализацию заголовка, единое отслеживание
  размеров мобильного экрана, очистку обработчиков и автоматическое закрытие при смене чата.
• Расширение не обращается к ExtBlocks, Tavern Helper, SillyImages и иным генераторам. Для генерации
  используется только текстовый API (напрямую или штатный Connection Manager SillyTavern) и прямой NovelAI API.
• Официальные промпты сохранены байт-в-байт.

SP Imagen 2.6.0 — БЫСТРЫЙ ГАЙД
--------------------------------
• Открой волшебную палочку → SP Imagen. Ниже основной кнопки находится
  полупрозрачная ссылка «💡 Быстрый гайд». Она также есть в главном меню

  можно нажать выделенную кнопку вместо «Далее». Никаких запросов
  генерации гайд не отправляет, настройки за пользователя не сохраняет.
• «Прервать обучение» работает на любом шаге, Escape тоже закрывает гайд.
  При смене чата обучение прекращается и его обработчики очищаются.
• Знаки «?» возле полей открывают отдельную справку: что означает поле,
  когда его заполнять, и что оставить по умолчанию.
  Термины внутри справки нажимаются — появляется простое объяснение.
• Подсветка и окна учитывают мобильный visualViewport, поворот телефона
  и экранную клавиатуру. Длинная карточка справки прокручивается внутри.
• Обучение и подсказки используют только встроенные модули SP Imagen,
  без обращения к Tavern Helper, ExtBlocks и генераторам других расширений.
• Файл official-prompts.js не изменялся, тексты пользовательских промптов
  и механизм генерации не затронуты.

SP Imagen 2.6.1 — восстановление после зависшей генерации
----------------------------------------------------------
• Завершение генерации не ждёт бесконечно загрузку файла или сохранение
  галереи: 60 секунд на файл и 45 секунд на сохранение чата.
• При неопределённом результате сохранения чата изображение остаётся в
  текущей галерее; предупреждение просит не перезагружать чат, пока не
  подтверждено сохранение. Это не ошибка генерации изображения.
• Повторный клик не запускает вторую генерацию параллельно в одном чате.
• Меню, настройки и обучение доступны во время генерации: прежний общий
  флаг блокировки меню удалён, вместо него используется ограничение
  только для команды генерации в рамках чата.
• Сроки ожидания вынесены в operation-timeout.js и используются в
  исходных модулях, без навешивания обработчиков поверх старых функций.
• Промпты не менялись.

Ограничение проверки: тесты без работающей установки SillyTavern;
сценарии подвисших saveChat и загрузки файла имитированы.

SP Imagen 2.7.0 — Профили, системные промпты и полный быстрый гайд
--------------------------------------------------------------------
• Пункт "Быстрый гайд" удалён из меню волшебной палочки; доступен из
  главного окна SP Imagen и настроек расширения.
• Гайд объясняет библиотеку подробно: поиск, поисковые теги,
  назначение тегов, фразы внешности, карандаш, выбор и перенос отметок
  в ракурсах, псевдонимы, поля для промпта и особенности тела.
• Если в текущем отфильтрованном списке есть записи, открывается первая
  видимая карточка. Если библиотека пуста, гайд предлагает нажать
  "+ Персонаж"; новый черновик не сохраняется автоматически.
• При выходе из библиотеки с несохранённой карточкой предлагается
  подтвердить отказ от изменений, чтобы не стереть их случайно.
• В "Профили" сохранены все три штатных формата Snapshot / Comic /
  Story Page; добавлено создание, редактирование, удаление и выбор
  личных дополнительных профилей по формату. Каждый профиль может
  включать/отключать части информации, стиль, ограничения реплик и
  негативный промпт. Изменения применяются в собственном движке Imagen.
• "Все промпты" — отдельное окно редактирования двенадцати остальных
  текстов-инструкций, включая поиск NPC, перевод, маркеры ракурсов,
  правила поиска, проверку подключения и шаблон настройки JSON.
  Для каждой есть восстановление исходного текста.
• Сохранённые пользовательские версии системных промптов лежат отдельно
  от поставляемых шаблонов в extensionSettings.spImagen.codePrompts.
• Каталог личных профилей по умолчанию пуст; штатные три формата
  находятся в собственном списке и не копируются в "Все промпты".
• Официальные режиссёрские тексты в official-prompts.js не изменены.
• Проверено: синтаксис JS, прежние регрессионные тесты, пользовательские
  профили и системные промпты, маршруты гайда (27/28 шагов) в Chromium
  на 360×640, 390×844 и 1280×800. Живой NovelAI/SillyTavern тест
  зависит от индивидуальной установки и здесь не выполнялся.

SP Imagen 2.8.0 — интерфейс, гайд, одежда из карточек
-----------------------------------------------------
ПРОФИЛИ: три встроенных режима сохраняются. Для своего промпта нажми
«Добавить промпт», напиши название и текст. Новый промпт включается
для всех режимов; его можно изменить или отключить в списке.
Переключатели источников открываются только в «Что использовать из чата».

ОДЕЖДА ИЗ КАРТОЧКИ И ПЕРСОНЫ (по умолчанию выключено):
«Настройки → Генерация → Найти одежду персонажей → Одежда из карточки и персоны».
Задай начало/конец блока отдельно для карточки и персоны. В карточке
нарратора укажи имя каждому участнику через ⟦ОДЕЖДА:Имя⟧...⟦/ОДЕЖДА⟧.
Примеры и кнопка копирования есть прямо в настройках.
Одежда из последних RP-постов важнее одежды из карточек; описание
активной персоны при совпадении имени важнее карточки нарратора.
SP Imagen читает эти блоки, но не изменяет оригиналы SillyTavern.

ГАЙД: сначала объясняет ракурсы, затем редактирование карандашом и
перенос тегов. Встроенные режиссёрские промпты и блок Text: не изменены.


НАСТРОЙКИ: ПОМОГАТОР 3000 И СВОИ ПРАВИЛА (2.9.0)
• Свои правила одежды и очистки теперь задаются двумя текстовыми метками — началом и концом,
  очистки и «Дополнительно». Вставь один реальный пример, нажми «Найти правило»,
  посмотри результат и «Добавить правило». Не забудь «Сохранить настройки».
• Для одежды [LOOK:Джи]blue sweater[/LOOK] заполняй: начало [LOOK:,
  после имени ], конец [/LOOK]. Имя и одежду не вставляй в поля границ.
• Готовая запись regex: Джи_outfit: blue sweater. Пример правила автоматически
  заполняет нужные группы name и outfit; их можно проверить кнопкой.
• Готовая HTML-запись: <div class="wardrobe-entry" data-name="Джи">
  <span class="outfit">blue sweater</span></div>.
• Очистка: [PRIVATE]служебная заметка[/PRIVATE] → убрать весь фрагмент.
  Исключение: ⟦SCORE:12⟧ → «Шкала отношений: 12».
• Старые правила и их поля при загрузке не переименовываются и не удаляются.
  Кнопки готовых примеров добавляют новые правила, не переписывая существующие.
