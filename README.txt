SP Imagen 2.4.1 — автономная версия для SillyTavern

УСТАНОВКА
1. Сделай резервную копию текущего расширения, библиотеки, пользовательских промптов и настроек.
2. Закрой SillyTavern и замени старую папку SP_IMAGEN_EXTENSION папкой из этого архива.
   Не устанавливай две копии SP Imagen одновременно.
3. Если раньше был установлен отдельный скрипт NESS/SP Imagen Media Slots в Tavern Helper,
   отключи его, чтобы старые кнопки не дублировались.
4. Перезапусти SillyTavern и обнови страницу с очисткой кэша (Ctrl+F5).

НАСТРОЙКИ
• Настройки библиотеки, сохранённые промпты, стили и предыдущие данные сохраняются
  в прежних ключах SillyTavern; удалять их не нужно.
• SP Imagen → Текстовая модель: выбери сохранённый профиль подключения
  SillyTavern или настрой прямой OpenAI-совместимый endpoint.
• SP Imagen → NovelAI: включи «Генерировать напрямую через NovelAI»,
  укажи постоянный API-токен NovelAI и модель.
• SP Imagen больше НЕ вызывает другие расширения для создания изображений,
  не создаёт временных скрытых RP-постов и не зависит от SillyImages.
• Параметр «Никогда не тратить Anlas» включён по умолчанию и проверяет
  право на бесплатную генерацию до отправки запроса.

ИНТЕРФЕЙС
• Открывается из настроек расширений или меню волшебной палочки.
• Под RP-сообщениями доступны Snapshot, Comic и Story Page; собственная
  галерея хранится в данных конкретного сообщения и чата.
• Для обновления существующего изображения используй ↻ в его галерее.

ДИАГНОСТИКА
• При неполном ответе режиссёра расширение повторяет текстовый запрос один раз;
  исходный ответ остаётся в переменной naicom_last_director_raw текущего чата.
• При сбоях проверь консоль браузера (F12) и сообщения SP Imagen.
• В тестах без реального аккаунта проверены парсер, ZIP NovelAI, работа текстового
  профиля, интерфейс галереи, переключение чатов и очистка обработчиков.
  Реальная генерация с подпиской и вашим сервером SillyTavern НЕ тестировалась.

ОФИЦИАЛЬНЫЕ ПРОМПТЫ
Файл official-prompts.js перенесён из исходной версии без изменений,
байт в байт. Сохранённые пользовательские промпты автоматически не стираются.

Безопасность: токены остаются в настройках клиента SillyTavern; не публикуй
экспорт настроек или файлы конфигурации с ключами.

SP Imagen 2.3.0
----------------
Все окна SP Imagen можно свернуть кнопкой «−» в заголовке и вернуть кнопкой «□».
В разделе «Промпты» → «Импорт / экспорт JSON» можно импортировать файл .json
или вставить JSON текстом, выгрузить текущие промпты, а также скачать шаблон
SP_IMAGEN_prompts_TEMPLATE.json, где каждое из трех полей промпта = "test".
Файл-шаблон — только образец структуры; для реальной генерации нужно
заменить "test" полноценными промптами. Импорт заменяет три промпта только
после явного подтверждения. Официальные промпты внутри расширения не менялись.


SP Imagen 2.4.0 — подключение и описания внешности (предыдущий релиз)
---------------------------------------------------
• Оба окна подключения строятся сразу, до любых сетевых действий. Поля
  текстовой модели не пропадают, даже если получение профилей SillyTavern
  не завершается. Список можно вручную обновить; сохранённый ID профиля
  остаётся выбранным и при временном сбое получения списка.
• В NovelAI при сбое подготовки формы показывается текст ошибки, а не
  одно название окна. Кнопки сворачивания работают с обоими окнами.
• Полная базовая внешность вставляется по умолчанию. Если выбранный
  ракурс пуст, подставляется всё базовое описание, даже если для других
  ракурсов настроены отдельные фрагменты.
• Если режиссёр пропустил техническую метку внешности, но указал точное
  имя известного библиотечного персонажа в отдельном блоке участника,
  код подставляет его базовое описание; незнакомцев не создаёт.
  Метка none по-прежнему означает намеренный силуэт/невидимые детали.
• Общая логика ракурсов объединена в одном модуле appearance-visibility.js
  вместо повторявшихся реализаций в runtime.js и library-runtime.js.
• Тексты режиссёрских и официальных промптов не редактировались.

ПРОВЕРКИ 2.4.0
• Синтаксис всех JS-файлов, офлайн-тесты транспорта/NovelAI/JSON и 8
  вариантов пустых ракурсов; браузерный стенд на изолированных подстановках
  API подтвердил полную отрисовку двух окон и сохранение полей при сворачивании.
• Полный запуск именно в пользовательской SillyTavern и авторизованные
  запросы к аккаунту NovelAI в этом окружении не проверялись.
