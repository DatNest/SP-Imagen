SP Imagen 2.0

SP Imagen — самостоятельное расширение. ExtBlocks ему не нужен.

УСТАНОВКА
1. Сделай резервную копию библиотеки и своих промптов.
2. Установи папку SP_IMAGEN_EXTENSION как стороннее расширение SillyTavern.
3. В Tavern Helper выключи старый NESS/SP Imagen Media Slots.
4. Полностью перезагрузи страницу.

ПЕРВЫЙ ЗАПУСК
• Библиотека, теги, цвета, палитра и настройки остаются в прежних постоянных ключах SillyTavern.
• Один раз SP Imagen скопирует ваши три режиссёрских промпта из прежнего профиля, если он ещё есть. После этого профили Images/Library можно удалить из ExtBlocks.
• Если в обновлении изменился официальный промпт, а вы редактировали свой, появится NEW! и выбор «Оставить мой» / «Поставить новый».

ПОДКЛЮЧЕНИЯ
• SP Imagen → Текстовая модель: выберите отдельный сохранённый профиль подключения SillyTavern с дешёвой моделью. Основной RP-профиль и модель чата не переключаются.
• Там же остаётся запасной режим: прямой endpoint, API-ключ и ID любой OpenAI-совместимой модели.
• Выбранная текстовая модель выполняет разбор NPC, композицию, помогаторы и три режиссёрских профиля.
• SP Imagen → NovelAI: постоянный API-токен, модель NAI, параметры и защита Anlas.
• SP Imagen → Стили: активный стиль отправляется дословным префиксом перед промптом.

ГДЕ ОТКРЫВАТЬ
• В настройках расширений: SP Imagen.
• В меню волшебной палочки: Библиотека, Настройки, Промпты.
• Под RP-постом: Snapshot / Comic / Story Page.

API-ключи не попадают в экспорт библиотеки или параметров генерации.
Важно: локальные проверки не заменяют проверку в вашей установленной SillyTavern.
