SP Imagen — аудит безопасности исходников
Версия проверки: 2.9.14. Анализ кода extension-only, без доступа к пользовательскому экземпляру SillyTavern.
Это не доказательство отсутствия уязвимостей в движке, браузере, других расширениях или выбранных API.

1. Исходящий трафик
- Запрос изображения и проверка подписки: https://image.novelai.net (официальный сервис NovelAI).
  Authorization: Bearer передаётся только этому узлу по HTTPS. Пользовательский endpoint теперь запрещён.
  Редиректы выключены, cookies и referrer не отправляются.
- Прямой текстовый API: выбранный пользователем OpenAI-совместимый HTTPS-сервер или HTTP loopback.
  API-ключ и RP-промпт уходят только на явно подтверждённый origin. Изменение origin блокирует отправку до повторного согласия.
  Старые подключения без approvedOrigin требуют повторного подтверждения после обновления.
  Профили SillyTavern отправляются через сам менеджер ST: контроль конечного сервера находится в ST.
- Прежний автоматический запрос к Wikipedia при поиске NPC убран. Имя NPC/фандом больше не уходят на Wikipedia.
- Галерея читает только изображения того же origin, что и Tavern, либо данные изображений data:image/png/jpeg/webp;base64.
  Внешние HTTP/HTTPS URL, URL без протокола, script:, blob: и SVG запрещены. Старые внешние картинки могут перестать показываться.

2. Работа с секретами
- NovelAI API-токен и ключ прямого текстового API сохраняются в стандартных настройках расширения SillyTavern.
  Это НЕ шифрованное безопасное хранилище; другие JS-расширения с доступом к той же странице теоретически смогут прочитать секрет.
  Для текстовой модели рекомендуется профиль подключения SillyTavern, который управляет секретом самостоятельно.
- Экспорты самой библиотеки и JSON встроенных промптов не включают API-ключи.
  Черновики постов используют локальное хранилище браузера и chat.extra, но не должны включать ключи.
- Ошибки HTTP провайдеров больше не вставляются дословно в пользовательский интерфейс: тело ошибки могло бы отражать приватные данные.

3. UI и исполняемый код
- Не используется загрузка сторонних JS/CDN или eval/new Function для пользовательских промптов.
- Единственная вставка innerHTML в index.js содержит статичную структуру UI (без пользовательских строк).
- Regex выполняется в локальном Worker с лимитом 1,5 секунды, чтобы не блокировать чат при некорректных выражениях.
- CSS переменные пользовательской темы ограничены допустимыми HEX-цветами.
- ZIP NovelAI имеет ограничения архивного и распакованного размеров (100/80 МБ).

4. Остаточные ограничения
- Любое расширение с привилегиями доступа к контексту SillyTavern потенциально может читать локальные данные
  и перехватывать сетевые запросы. SP Imagen не может обеспечить изоляцию от других вредоносных расширений.
- API-ключ NovelAI передаётся NovelAI, ключ текстового API — выбранному провайдеру, а RP-фрагменты,
  отправляемые текстовой модели, обрабатываются её провайдером. Это часть заявленной функциональности.
- Политики безопасности аккаунтов у поставщиков моделей и хостинга SillyTavern выходят за пределы аудита.
- Пользовательские RP-черновики хранятся в localStorage, поэтому на общем устройстве могут быть доступны другим пользователям профиля браузера.
- Динамический тест сетевой панели в живой SillyTavern с реальными токенами НЕ проводился. Использовать реальные ключи для CI нельзя.

Контроль:
- tests/security-network.mjs — проверка spoofed URL, назначения токенов, запрета редиректов, удалённых медиа и отсутствия неявной Wikipedia.
- .github/workflows/safety-tests.yml — Node 22, без сторонних пакетов, без secrets; запуск unit и core-integrity.
