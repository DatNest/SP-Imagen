SP Imagen 2.9.15 — единый редактор, безопасная галерея и защита подключений
21 ноября 2026

ВНЕШНОСТЬ
• Полноэкранный конструктор удалён. Редактирование происходит во вкладке «Внешность» карточки персонажа.
• Три переключаемых режима в одной панели: «Ракурсы», «Под одеждой» и «NSFW».
• Все три работают по одной схеме подсветки: нажми на тег, чтобы назначить или снять его. Отдельной колонки «Выбрано» нет.
• Ракурсы используют прежние исходные постоянные признаки и NESS_VIS.
• «Под одеждой» — собственный каталог и существующие области видимой кожи через NESS_SKIN.
• NSFW — собственный каталог и области: «Анатомия груди», «Нижняя передняя анатомия», «Нижняя задняя анатомия». Подстановку видимости определяет режиссёр по инструкции «только если открыто и видно».
• Название разделителя сворачивает и разворачивает его теги. Рядом всегда показано количество тегов.
• После выбора тега ←/→ переставляют его на соседнее физическое место; ↑/↓ переносят в соседний именованный раздел (если существует).
• ПКМ на теге или удержание ⠿ на телефоне открывает копирование/перенос в другой режим.
• Добавление, переименование, удаление разделителей, undo/redo.
• Старые nudeUpper/nudeLower сохраняются дословно, без автоматической попытки угадать новые анатомические области. Настройки ракурсов, кожи и разделителей переживают JSON-импорт/экспорт.
• При изменении свободного текстового описания уцелевшие смещения тегов сохраняются, если текст этой фразы не был затронут.

ГАЛЕРЕЯ И ПАМЯТЬ
• Новые PNG сохраняются как файлы в SillyTavern; в пост хранится лишь путь. При неудаче сохранения файла запрещено сохранять большой inline base64.
• По явному подтверждению 🗑 версия удаляется из галереи, потом сохраняется чат и через штатный одноимённый API SillyTavern удаляется принадлежащий SP Imagen PNG — только если на него больше нет ссылок в текущем чате.
• Старые дубликаты в sp_imagen_embeds удаляются из сообщения, чтобы миграция не восстановила стёртую версию.
• Чужие файлы, не принадлежащие SP Imagen, не удаляются; старые внешние ссылки не уничтожаются и открываются вручную с предупреждением.
• Другие чаты не сканируются. Если файл вручную скопирован в другой чат, физическое удаление может нарушить там его ссылку — об этом есть предупреждение.

ПРИВАТНОСТЬ И СЕТЬ
• Токен NovelAI отправляется только по HTTPS на https://image.novelai.net, без следования редиректам.
• Прямой текстовый API требует явного подтверждения HTTPS-сервера по origin; localhost допускает HTTP. Перенаправления, сторонние cookies и referrer запрещены.
• Прямые подключения через профили SillyTavern продолжают работать с профилем в менеджере ST.
• Убраны автоматические Wikipedia-запросы с именами NPC/фандомами.
• Внешние изображения из старой истории не загружаются автоматически, но сохраняются и могут быть открыты явно.
• Удалены дословные тела ошибок сторонних API, которые могли отражать приватные данные.

ПРОВЕРКА
• GitHub Actions Node 22: 43/43 unit/regression tests, дополнительно node --check для всех упакованных .js файлов.
• Тесты охватывают реальные нормализаторы, постоянные ракурсы, открытые участки, разделители, NSFW изоляцию, библиотечный JSON roundtrip, сетевые блокировки, легальные успешные API-вызовы, сохранность старых изображений, удаление файлов и мобильный таймер.
• Тест в реальном браузере SillyTavern с персональным подключением и токеном не проводился. Синтетические тесты не заменяют smoke-test после обновления.
