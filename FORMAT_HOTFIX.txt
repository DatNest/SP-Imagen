SP Imagen v2.8.9 — исправление формата ответа режиссёра

База: v2.8.8, полностью сохранён механизм генерации и публикации изображений v2.8.7.
Причина возможного сбоя: новая подсказка для диалогов описывала УСТАРЕВШИЙ JSON scene/people/bubbles/text вместо единственного рабочего HTML/IMG-транспорта.

Изменения:
• Дополнительная подсказка теперь только ограничивает число реплик и слов, строго закрепляя тот же HTML-формат ответа, что был в первом ZIP.
• Подсказка располагается ПЕРЕД разделом OUTPUT CONTRACT исходного режиссёра, а не в самом конце системной инструкции.
• Вторая попытка при невалидном ответе теперь отправляет уточнение по формату (раньше делалась дословно та же попытка).
• Код парсера изображения image-transport.js, нормализация промпта, API NovelAI, собственная галерея и вся фактическая генерация не изменены.
• Настройки Генерации и поиск одежды v2.9.6 из v2.8.8 сохранены.

Для уже сохранённого пользовательского переопределения «Лимиты текста» может потребоваться «Восстановить стандартное» в Редакторе промптов, если там осталась прежняя инструкция про legacy JSON. Для нового дефолта старого текста больше нет.
