SP Imagen 2.4.1 — мобильные окна (18.11.2026)

- Все окна SP Imagen теперь монтируются под корневым элементом документа,
  вне преобразований (transform) и прокрутки body, которые могут задавать темы SillyTavern.
- Один модуль viewport-overlay.js отвечает за размещение как окон SP Imagen,
  так и редактора библиотеки, экрана подготовки и окна итогового промпта.
- При изменении visualViewport (мобильная клавиатура, вращение, масштабирование,
  прокрутка) размеры и положение обновляются без разъезда с видимой областью.
- Мобильные редакторы ограничены высотой самого окна и скроллятся внутри,
  а не растягиваются за экран; при закрытии слушатели удаляются.
- Никакие промпты и поведение генерации изображений не менялись.
- Тесты: 390×844, 360×640, 844×390, прокрутка страницы;
  имитация изменения visualViewport при открытии клавиатуры.

SP Imagen 2.2.0 — изменения КОДА

1. Новый изолированный разборщик ответа режиссёра: HTML-обёртки naicom/image_lite,
   одиночный img, JSON, кодовые блоки; проверка ровно одной инструкции и корректного JSON.
   При некорректном результате выполняется одна повторная попытка, исходник сохраняется.
2. Отменяемые текстовые запросы и ограничение времени ожидания; отмена при смене чата.
3. Встроенный ZIP-декодер ответа NovelAI; обработка PNG для методов store/deflate.
4. Генерация изображений и повторная генерация внутри SP Imagen: без вызовов SillyImages,
   глобальной переменной передачи поста и скрытых сообщений.
5. Сохранение изображения непосредственно в галерею выбранного RP-поста;
   проверка актуальности чата и откат локальных изменений при ошибке сохранения.
6. Блокировки и ссылки на расширение локализованы в модулях, удалены общие глобальные
   объекты и зависимости от window.parent/window.top.
7. Объединены идентичные CSS-правила и справочные константы из модулей библиотеки
   и сценариев; визуальные стили сохранены.
8. Исправлена первичная отрисовка кнопок под RP-постами.
9. Выключено автоматическое обновление manifest.json для избежания замены патча.
10. Файл official-prompts.js совпадает с исходным по SHA-256:
    4fe4e58666b245192310e4750e23d9f014cef13241fa8473f6f309eaadea5513

Проверки: синтаксис всех JS-модулей, Node.js smoke tests, Chromium UI smoke tests.
Ограничение: отсутствует возможность провести реальную авторизованную генерацию
NovelAI и полную интеграцию с пользовательским экземпляром SillyTavern.


SP Imagen 2.3.0 — редакторы и JSON
----------------------------------
• В главном окне, редакторах промптов, настройках, библиотеке, предпросмотре и дополнительных диалогах добавлены кнопки сворачивания/разворачивания.
• Центр промптов и текстовый редактор имеют ограниченную высоту с внутренней прокруткой; содержание не заставляет окно расти.
• Импорт/экспорт трех режиссерских промптов через JSON: текстовое поле или файл .json, проверка формата и подтверждение перед заменой.

• Отдельный импорт JSON настроек генерации из файла, существовавший в 2.2.0, сохранен.
• Карточки подготовки сцены (посты, одежда, композиция, участники, NPC) можно сворачивать независимо.


SP Imagen 2.4.0 — чистая реализация вместо надстроек
---------------------------------------------------
1. Распаковка зависимости окна текстовой модели от асинхронного списка
   профилей; настройки создаются сразу, поиск профилей работает отдельно.
   Сохранённый профиль не сбрасывается при неудачном обнаружении.
2. Окно NovelAI монтирует содержимое до подготовки контролов, ошибки
   отрисовки видны в окне, вместо пустой панели с одним заголовком.
3. Исправлена видимость целых строк ввода с учётом атрибута hidden.
4. Одна реализация разметки внешности в appearance-visibility.js. Удалены
   дубликаты из runtime.js/library-runtime.js, константы и селекторы CSS
   объединены без каскадных дополнительных фиксов.
5. Если ракурс отсутствует или не содержит видимых фрагментов, работает
   fallback полного базового описания. Запись обрабатывает и выбранный,
   но пустой ракурс. Пропущенные метки восстанавливаются по точному имени
   известного персонажа без добавления NPC.
6. Файл official-prompts.js сохранён байт в байт, как в 2.3.0.

Регрессионные проверки: tests/appearance.mjs и tests/smoke.mjs;
браузерный mock-тест обоих диалогов (включая искусственно зависшее получение
профилей и сохранение ввода при сворачивании). Реальный хост не тестировался.
