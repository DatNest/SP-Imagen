SP Imagen 2.4.1 — мобильные окна (18.11.2026)

- Все окна SP Imagen теперь монтируются под корневым элементом документа,
  вне преобразований (transform) и прокрутки body, которые могут задавать темы SillyTavern.
- Один модуль viewport-overlay.js отвечает за размещение как окон SP Imagen,
  так и редактора библиотеки, экрана подготовки и окна итогового промпта.
- При изменении visualViewport (мобильная клавиатура, вращение, масштабирование,
  прокрутка) размеры и положение обновляются без разъезда с видимой областью.
- Мобильные редакторы ограничены высотой самого окна и скроллятся внутри,
  а не растягиваются за экран; при закрытии слушатели удаляются.
- Никакие промпты и поведение генерации изображений не менялись.
- Тесты: 390×844, 360×640, 844×390, прокрутка страницы;
  имитация изменения visualViewport при открытии клавиатуры.

SP Imagen 2.6.1 — controlled operation lifetime (18.11.2026)
----------------------------------------------------------
• Added shared operation-timeout.js deadlines; runtime text/metadata timeouts
  use the same utility without changing timeout values or prompts.
• Media gallery file upload has 60 s deadline; chat save has 45 s deadline.
• On a chat-save timeout, keep the produced image attached to the current
  message and show an explicit warning that persistence is unconfirmed.
  Confirmed save failures still roll back the gallery change.
• Removed global commandBusy; only duplicate generate clicks within a chat
  are suppressed. The SP Imagen menu and guide stay usable.
• Included tests/operation-locks.mjs and tests/publish-regression.mjs for
  timeouts, rejection rollback, repeat requests, and menu independence.
• All official prompt bytes remain unchanged from 2.6.0.
